About the Department

The Department of Computer Engineering at Shah & Anchor Kutchhi Engineering College (SAKEC) has been imparting high-quality technical education since 1996. Offering undergraduate (B.Tech), postgraduate (M.Tech), and Ph.D. programs, the department focuses on bridging foundational concepts with contemporary technological demands such as AI, Cloud Computing, Cybersecurity, and IoT.

Vision: To achieve academic excellence in computer engineering education and research, developing socially responsible, technically competent professionals capable of adapting to emerging global paradigms.

Department Laboratories

Specialized computing and hardware infrastructure equipped with high-end Dell/HP systems and licensed software suites.

AI & Machine Learning Lab

High-compute GPU workstations dedicated to Deep Learning, Computer Vision, and Data Science models.

  • Hardware: Core i7, 32GB RAM, Dedicated NVIDIA GPUs
  • Software: Python, PyTorch, TensorFlow, OpenCV, Anaconda

Software Testing & Web Lab

Focused on modern web engineering, automated browser validation, and software quality assurance.

  • Hardware: Dell OptiPlex Core i5 Systems, High-Speed LAN
  • Software: Selenium, Helium, Jest, Next.js, Git, VS Code

Network & Cybersecurity Lab

Hands-on testbed for packet analysis, routing protocols, ethical hacking, and network simulation.

  • Hardware: Cisco Routers, Managed Gigabit Switches
  • Software: Wireshark, Kali Linux, Cisco Packet Tracer

Database & Big Data Lab

Configured for SQL, distributed NoSQL databases, and enterprise data processing applications.

  • Hardware: Network Storage Arrays, Dedicated Server
  • Software: Oracle 19c, PostgreSQL, MongoDB, Apache Hadoop

IoT & Embedded Systems Lab

Microcontroller and sensor interfacing station for hardware prototyping and edge computing.

  • Hardware: Raspberry Pi, ESP32, Arduino kits, DSOs
  • Software: EasyEDA, Arduino IDE, FreeRTOS, Proteus

Project & Research Lab

Dedicated incubation workspace for capstone projects, SIH hackathons, and published student research.

  • Hardware: High-Performance Development Nodes
  • Access: Open 24/7 during Hackathons & Contests
